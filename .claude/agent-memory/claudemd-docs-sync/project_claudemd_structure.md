The docs file list lives under the section header `## IMPORTANT: Docs-First Rule` in CLAUDE.md (project root).

Each entry uses the format:
```
- /docs/filename.md
```

Ordering is append-order (not alphabetical) — new entries go at the end of the bullet list.

**Why:** This is how the file was originally structured and has been consistently maintained across additions.

**How to apply:** When adding a new /docs entry, append it after the last existing bullet under `## IMPORTANT: Docs-First Rule`, matching the `- /docs/filename.md` format exactly.
